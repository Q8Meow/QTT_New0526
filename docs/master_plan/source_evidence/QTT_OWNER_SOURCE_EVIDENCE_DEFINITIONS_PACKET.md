## 1. Purpose

This packet tells Codex and source-evidence tooling what the owner permits for source discovery, retrieval, acceptance review, private-document handling, revalidation scheduling, and connector unlock gating.

This packet does **not** make any external fact true. It does not define venue API behavior, order fields, fees, tick sizes, settlement rules, SDK behavior, backend options, runtime balances, market data, replay results, paper results, live reachability, order authority, or profit evidence. It also does not make any venue execution-lifecycle, fill-integrity, cashflow/PnL, latency-component, settlement-finality, reconciliation, or cross-venue normalization fact true; those remain accepted-source-packet and runtime-receipt gated.
